# 应用图标重做（简短设计）

日期：2026-11-16

## 目的

现在的 `assets/icons/favicon.ico` 是一张插画：文档、"SDTM" 文字、DNA、齿轮和三把锁，背景是不透明的白色方块。缩到任务栏的 32 像素和标题栏的 16 像素时看不清，白色方底在暗色背景上也很突兀。新图标只表达"数据工具箱"一个意思，背景透明，小尺寸下也能认出来。

## 目标

- 背景透明，没有方形白底。
- 16、32、48、64、128、256 六个尺寸都放进同一个 `favicon.ico`。
- 在亮色和暗色背景上都清楚。
- 以后改颜色或图案时，改源文件后重新生成即可，结果可以重复得到。

## 不做的事

- 不改程序里的工具图标、主页卡片和侧边栏。
- 不改文件名和引用位置。`resources.py`、PyInstaller spec、Inno 安装脚本都继续读 `assets/icons/favicon.ico`。
- 不新增运行或开发依赖。

## 做法比较

1. **手写 SVG + 脚本生成 ico（已选）**：SVG 作为源文件，用已有的 PySide6 渲染各个尺寸后打包。不用装新依赖，结果可重复。
2. 在方案 1 的基础上给 16 和 32 单独画一版简化图：小尺寸最清晰，但要维护两份 SVG。先不做；生成后看了实际效果再决定要不要补。
3. 用 Inkscape、ImageMagick 或在线工具转换：要装外部工具，结果也不容易重复，不采用。

## 图案（用户已选"C 四格工具"）

- 2×2 四个圆角方块，四周和中间留空，背景透明。
- 每格放一个白色图案，和主页的工具卡片对应：
  - 左上：蓝色，转换（双向箭头）；
  - 右上：青色，拆分（左右两栏）；
  - 左下：紫色，提取（放大镜或几行文字）；
  - 右下：橙色，模糊化（划掉的眼睛）。
- 配色沿用草图里的蓝、青、紫、橙。

## 实现要点

- 新增 `assets/icons/app_icon.svg`（源文件，viewBox 256×256）。
- 新增 `scripts/build_icon.py`：用 `QSvgRenderer` 把 SVG 渲染成六个尺寸的 PNG，再写成 ico 文件。每个尺寸存成一条 PNG 记录。Qt 没有现成的多尺寸 ico 写入，ico 的文件头由脚本自己写。
- 生成结果覆盖 `assets/icons/favicon.ico`。
- 验收：
  - 用 Qt 读回新 ico，确认六个尺寸都在，并且四个角是透明的；
  - 把 16 和 32 放大给用户看实际效果；
  - 跑全部测试（其中 `test_selfcheck.py` 会检查图标路径）。

## 留给实现者决定

- 每格图案的具体画法和线条粗细，以 16 和 32 下能分辨为准。
- 脚本的命令行参数（例如输出路径）怎么设计。
