# 工作表拆分（sheet_split）

把 Excel 工作簿的每个 sheet 各导出为一个 CSV。该规则也被"格式转换"的 XLSX→CSV 模式复用（可只导出第一个 sheet）。

## 输入

- `.xlsx`、`.xlsm`（可多个文件，或选择文件夹；跳过 `~$` 开头的临时锁文件）。
- 用 openpyxl 只读模式加载，`data_only=True`：读取公式的缓存结果，不读公式本身。

## 参数与默认值

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 输出位置 `output_dir` | 与原文件相同 | 可指定另一个文件夹（不存在则创建） |

没有"覆盖原文件"选项（输出是 CSV，扩展名与输入不同）。

## 处理步骤

1. 逐个文件加载工作簿，按 sheet 顺序处理。
2. 每个 sheet 的单元格转为字符串：
   - 空单元格 → 空字符串；
   - 日期/日期时间单元格按其 `number_format` 渲染（见下）；
   - 其他一律 `str(value)`（数字不做额外格式化，例如 `1.5`、`12`）。
3. 去掉末尾的全空行；去掉所有行共同的末尾全空列（以整个 sheet 中最靠右的非空列为界）。
4. 以 CSV 写出：逗号分隔，行尾 `\r\n`，含逗号/引号/换行的字段按标准 CSV 加双引号。

### 日期渲染

取 `number_format` 的第一段（`;` 之前），转小写，去掉 `[...]` 和 `"..."` 片段，然后：

1. 以第一个 `h` 为界拆成日期部分和时间部分。
2. 日期部分按顺序提取连续的 `y`/`m`/`d` 记号；分隔符优先取 `/`，其次 `-`，其次 `.`，都没有则用 `-`。
3. 记号渲染：`y` 长度 ≤2 → 两位年，否则四位年；`m`/`d` 长度 ≥2 → 补零两位，否则不补零。没有任何记号时输出 `YYYY-MM-DD`（分隔符按上条）。
4. 仅当值是日期时间时才可能带时间：时间不是 00:00:00，或时间部分含 `h`/`s`，则追加 ` HH:MM`；时间部分含 `s` 时追加秒（` HH:MM:SS`）。纯日期值不带时间。

例：`yyyy/mm/dd` → `2020/03/04`；`yyyy-mm-dd hh:mm` → `2020-03-04 10:05`；`yy.m.d` → `21.12.1`。

## 输出位置与命名

- 导出全部 sheet：`<stem>_<安全sheet名>.csv`，例如 `book.xlsx` 的 sheet `数据` → `book_数据.csv`。
- 只导出第一个 sheet（格式转换模式）：`<stem>.csv`。
- 安全 sheet 名：
  - 非法字符 `< > : " / \ | ? *` 和控制字符（U+0000–U+001F）→ `_`；
  - 去掉末尾的空格和点；
  - 结果为空、`.`、`..` → `Sheet`；
  - 属于 Windows 保留名（`CON PRN AUX NUL COM1–COM9 LPT1–LPT9`，不区分大小写）→ 末尾加 `_`。
- 同一工作簿内安全名重复时，对安全名加 `_1`、`_2`……（先去重，再加 `<stem>_` 前缀），例如 `a<b` 与 `a|b` → `book_a_b.csv`、`book_a_b_1.csv`。
- 目标文件已存在时再自动加 `_1`、`_2`……，不覆盖已有文件。
- CSV 一律 UTF-8 BOM（`utf-8-sig`）；空 sheet 输出只含 BOM 的文件。
- 输出先写入同目录的临时文件，成功后再替换到目标位置。

**v3 变更**：v2 的输出名只有安全 sheet 名（`数据.csv`），v3 加了原文件名前缀（`book_数据.csv`），避免多个工作簿之间互相冲突。

## 统计与结果

- `files`：成功处理的文件数（该文件没有任何错误）。
- `sheets`：成功写出的 sheet 数。

## 边界情况

- 未选择文件：报错"请先选择要拆分的 Excel 文件"。
- 单个文件失败不影响其他文件：
  - 无法读取（常见于文件已在 Excel 中打开）：记为错误"无法读取文件（可能已在 Excel 中打开）"；
  - 其他异常（如文件损坏）：记为"读取失败：<原因>"。
- 单个 sheet 写出失败：记为错误"<sheet 名>: <原因>"，继续处理下一个 sheet。
- 每个 sheet 开始前检查取消；取消后不再处理后续内容，已完成的输出保留。

## 已知限制

- 读取的是公式的缓存结果；从未在 Excel 中保存过的程序生成文件，公式单元格可能为空。
- 数字不按单元格的数字格式渲染（如千分位、百分比），一律是值本身的字符串形式。
- 只读模式不展开合并单元格，合并区域只有左上角有值。
- Excel 本身不允许 sheet 名含 `/ \ ? * [ ] :`，所以实际出现的非法字符只有 `< > " |` 和控制字符。

## 标准样例

`tests/golden/sheet_split/basic/`：覆盖多种日期格式（`yyyy/mm/dd`、`yy.m.d`、带时间、时间为 0 点的纯日期格式）、中文 sheet 名、含非法字符且清洗后重名的 sheet、保留名 sheet（空 sheet）、含逗号和引号的字段、末尾空行与空列。
