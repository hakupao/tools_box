# EDC 站点添加（edc）

从 Excel 当前选中的单元格开始，逐行向下读取站点编号，在目标浏览器窗口里按录制好的 7 个屏幕位置依次点击，把站点添加到 EDC。程序只负责"读取 → 复制 → 激活窗口 → 点击 → 切回 Excel"，不读取浏览器页面内容。

实现上分两层：

- **一段运行**（`run_segment`）：从某个单元格开始，处理到空单元格、到达行数上限或第一次停下为止。
- **整次运行**（`EdcSession`）：第一段加上用户在每次停下后选择"重做 / 跳过"所续跑的各段，最后汇总。

点击、剪贴板、Excel、窗口激活和等待都通过可替换的执行接口完成，测试时用假实现记录动作序列（见"动作序列格式"），不操作真实屏幕。

## 输入

- Excel：正在运行的 Excel 中当前选区的左上角单元格作为起点（工作簿、工作表、行、列）。读取的是单元格的显示文本（`.Text`）。之后只在同一列向下移动。
- 配置：点击位置、`max_loops`、`step_delay`、目标窗口（见"配置"）。
- 没有设置目标窗口时不开始运行，报错"未设置目标窗口"。
- 读取 Excel 选区失败时不开始运行，报错"无法读取 Excel 选中的单元格：<原因>"（如果原因本身已是面向用户的提示，例如"请先在 Excel 中选中第一个站点所在的单元格"，则原样显示）。

## 每一行的 11 个步骤

| 步骤 | 名称 | 动作 | 之后等待 |
| --- | --- | --- | --- |
| 1 | 读取单元格 | 读取单元格显示文本，去掉首尾空格 | 无 |
| 2 | 复制到剪贴板 | 把去空格后的值复制到剪贴板 | 0.1 s |
| 3 | 激活目标窗口 | 找到并激活目标浏览器窗口 | 0.1 s |
| 4 | 点击【新建】 | 点击录制的位置 | `step_delay` |
| 5 | 点击【查找】 | 同上 | `step_delay` |
| 6 | 点击【搜索框】并粘贴 | 点击，等待 0.05 s，按 Ctrl+V | `step_delay` |
| 7 | 点击【搜索】 | 点击 | `step_delay` |
| 8 | 点击【选择】 | 点击 | `step_delay` |
| 9 | 点击【ok】 | 点击 | `step_delay` |
| 10 | 点击【确认】 | 点击 | `step_delay` |
| 11 | 切回 Excel 并选中下一行 | 激活 Excel，选中同列下一行的单元格 | 0.1 s |

- 第 1 步读到的值去掉首尾空格后为空，这一行就是**空单元格**：本段正常结束，不算停下，也不做后面的步骤。只有空格的单元格同样算空。
- 第 1 步之后、第 2 步之前，报告一次进度：`(第几行, 预计总行数, "Excel <地址>：<值>")`，并写一行日志。"第几行"从本段起点算起，从 1 开始。
- 预计总行数：每段开始时从起点向下逐个读取单元格，直到第一个空单元格或行数上限为止，计数非空的行。读取出错时，总数取"上限行 − 起点行"。这一步只用于显示进度，不影响处理。

## 起点和 `max_loops`

- 第一段的起点是 Excel 当前选中的单元格，记为第 `S` 行。
- 整次运行的**上限行**固定为 `S + max_loops`：只处理行号小于上限行的行，也就是最多处理到第 `S + max_loops − 1` 行。
- 续跑的各段沿用同一个上限行。"重做本行"不额外占用次数：重做的行号不变，上限也不变。
- 处理完上限行之前的最后一行后，本段以"到达上限"结束。

## 停止条件

一段运行在以下任一情况下结束：

1. **空单元格**：第 1 步读到空值（见上）。正常结束。
2. **到达上限**：已处理到上限行的前一行。正常结束。
3. **停下**：某一步出错或用户按了 ESC。这一行没有完成，本段结束，等待用户选择。

每一步开始前依次检查：

1. 任务是否被强制取消（例如关闭程序）→ 立即中止，不进入汇总。
2. 用户是否按了 ESC → 这一行在**这一步**停下，原因"已按 ESC 停止"，标记为用户停止。ESC 不会打断正在进行的一步，而是在下一步开始前生效。

每一步执行时出现异常 → 这一行在这一步停下，原因：

- 异常类名为 `FailSafeException`（鼠标移到屏幕角落触发的安全停止）→ "鼠标移到了屏幕角落，已触发安全停止"；
- 其他异常 → 异常消息；消息为空时用异常类名。例如目标窗口已关闭时，第 3 步的原因为"找不到目标窗口：<标题>（<进程名>）"。

停下时记录：单元格、已读到的值（第 1 步停下时为空）、步骤号（1–11）、原因、是否为用户停止。步骤号为 1 表示这一行还没有做任何动作。

出错后**不自动重试**，避免同一个站点被重复添加。

## 停下后的 3 个选择

- **重做本行**（redo）：从这一行的第 1 步重新开始一段新的运行。重做前应先在 EDC 中确认这一行是否已经添加过。
- **跳到下一行**（skip）：这一行记为"已跳过"，从下一行开始新的一段。如果下一行已到达上限行，整次运行结束。
- **结束**（end）：整次运行结束。这一行记为"出错"，**例外**：用户按 ESC 且停在第 1 步（这一行还没开始），不计入出错，也不计入跳过。

新的一段从指定单元格开始，不再读取 Excel 选区；每段开始时重新预计总行数。

## 汇总规则

整次运行结束后：

- 成功的行：所有段中完成全部 11 步的行，按完成顺序，每行 `<地址> <值>`。
- 跳过的行：每行一条警告"已跳过（第 <k> 步「<步骤名>」：<原因>）"。
- 出错的行：每行一条错误"出错（第 <k> 步「<步骤名>」：<原因>）"。
- 统计：`succeeded`、`skipped`、`failed` 三个计数。

地址为列字母加行号，例如第 1 列第 5 行为 `A5`，第 27 列为 `AA`，第 52 列为 `AZ`。

## 目标窗口

录制第一下点击时，记住被点击的顶层窗口：窗口句柄、标题、进程名（小写 exe 文件名，例如 `chrome.exe`）。也可以从窗口列表中手动选择。

每一行的第 3 步，在当前所有可见、有标题的顶层窗口（不含本程序的窗口）中按以下顺序匹配，第一条命中即使用：

1. 句柄相同且进程名相同（不区分大小写）的窗口；
2. 进程名相同、标题完全相同的第一个窗口；
3. 进程名相同的窗口恰好只有 1 个时，使用它；
4. 都不满足 → 第 3 步停下，原因"找不到目标窗口：<标题>（<进程名>）"。

激活：窗口已关闭 → "目标窗口已关闭"；最小化时先还原；激活失败时按一下 Alt 再试 1 次，仍失败 → "无法激活目标窗口"。

## 配置

保存在配置文件的 `edc_site_adder` 节：

| 键 | 默认 | 规则 |
| --- | --- | --- |
| `max_loops` | 100 | 整数 1–9999，否则用默认值 |
| `step_delay` | 0.3 | 数字 0.1–5.0（秒），否则用默认值 |
| `click_positions` | 见下 | `{"<步骤键>": {"x": 整数, "y": 整数}}`；缺少或无效的步骤用默认值，未知键忽略 |
| `target_window` | `null` | `{"hwnd": 整数, "title": 文本, "process": 文本}`，无效时视为未设置 |

步骤键与默认位置（物理像素）：`新建` (241, 212)、`查找` (1137, 460)、`搜索框` (817, 409)、`搜索` (1040, 406)、`选择` (699, 471)、`ok` (1121, 758)、`确认` (1038, 728)。

v2 中的 `retry_count` 读取时忽略，保存时不写。

迁移（不修改任何旧文件）：

1. 配置文件中有 `edc_site_adder` 节且不为空 → 使用它。
2. 否则，配置文件顶层含 `max_loops` 或 `click_positions` → 把顶层当作本工具的配置（v2 的旧布局）。
3. 否则，依次查找 v2 的独立配置文件 `edc_site_adder_config.json`（打包版程序目录、源码 `utils` 目录、v2 页面目录）；第一个可读且含上述任一键的文件被复制到 `edc_site_adder` 节并使用。
4. 都没有 → 全部默认值；旧配置没有目标窗口，第一次运行前需要录制或选择窗口。

## 动作序列格式

测试用的假执行接口把每次调用记为一行（UTF-8，LF 换行），标准样例 `tests/golden/edc/<case>/expected/trace.txt` 逐字节比较：

| 行 | 含义 |
| --- | --- |
| `excel.selection -> A2` | 读取 Excel 选区，结果为 A2 |
| `excel.text A3` | 读取 A3 的显示文本（包括预计总行数时的读取） |
| `excel.focus A4` | 切回 Excel 并选中 A4 |
| `clipboard.copy SITE-1` | 复制文本 |
| `window.activate` | 激活目标窗口 |
| `screen.click 241 212` | 点击屏幕坐标 |
| `screen.paste` | Ctrl+V |
| `sleep 0.3` | 等待秒数（最短的十进制写法，如 `0.1`、`0.05`） |

出错的调用也会先记一行再抛出异常。标准样例的驱动方式（`tests/dataforge/golden.py` 的 `_run_edc`）：

- `params.json`：`cells`（行号 → 文本，A 列，工作簿 `Book1`，工作表 `Sheet1`）、`start_row`（Excel 选区所在行）、`max_loops`、`step_delay`、`fail`（`[{"call": "screen.click", "nth": 12, "message": "boom", "exc": null}]`：该动作整次运行中第 nth 次调用时抛出异常，`exc` 为异常类名或 `null`）、`esc_after`（动作序列达到这么多行之后视为按了 ESC，只对第一段有效）、`choices`（每次停下时依次使用的选择，用完后取 `end`）。点击位置用默认值，目标窗口固定。
- 每次停下时追加一行 `== stop <地址> step <k>: <原因> -> <选择>`。
- 结束后追加汇总：每个成功行 `succeeded <地址> <值>`，然后每个跳过行 `skipped <地址> step <k>`，然后每个出错行 `failed <地址> step <k>`。

## 已知限制

- 能检测到的"失败"只有异常类错误：目标窗口找不到或无法激活、Excel 出错、剪贴板出错、鼠标移到屏幕角落触发安全停止、用户按了 ESC。程序无法判断一次点击是否真正生效：网页加载慢、弹窗位置变化、点到了别处，都不会被发现，这一行仍会被记为成功。
- 点击位置是录制时的屏幕坐标，浏览器窗口移动、缩放比例或分辨率变化后需要重新录制。
- 只沿同一列向下处理，不跳过中间的空单元格（遇到空单元格即结束）。
