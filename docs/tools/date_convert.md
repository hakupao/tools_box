# 日期转换（date_convert）

## 输入

- 一段多行文本（界面中粘贴），按行处理；无文件输入输出。
- 换行按 `splitlines()` 切分，结果用 `\n` 连接（空行保留为空行）。

## 参数与默认值

无参数。

## 处理步骤（每一行）

1. 先去掉首尾空白；结果为空 → 输出空字符串。
2. 不含 `/` → 原样返回（已去空白的值）。
3. 按 `/` 切分；任一部分不是整数 → 原样返回。
4. 超过三段 → 原样返回。
5. 年不在 1000–9999 → 原样返回。
6. 只有年 → `YYYY`。
7. 月不在 1–12 → `YYYY`。
8. 只有年月 → `YYYY-MM`。
9. 年月日三段：日期在该年该月的真实日历中有效 → `YYYY-MM-DD`；无效 → `YYYY-MM`。
   - **v3 变更**：v2 只检查日在 1–31，`2021/02/31` 会得到 `2021-02-31`；v3 用真实日历校验（含闰年），得到 `2021-02`。

## 输出位置与命名

不产生文件。结果显示在界面的结果框，可一键复制。即时工具，不记入"最近使用"。

## 编码

标准样例中的 `.txt` 为 UTF-8 无 BOM、`\n` 换行、末行无换行符。

## 边界情况

| 输入 | 输出 |
| --- | --- |
| `2021/2/3` | `2021-02-03` |
| `2020/02/29` | `2020-02-29` |
| `2021/02/31` | `2021-02` |
| `2010/99/99` | `2010` |
| `2010/10/99` | `2010-10` |
| ` 2010/1 ` | `2010-01` |
| `999/01/01`、`2010/10/ab`、`2010/`、`2010/1/2/3`、`abc` | 原样返回 |
| `2010` | `2010` |

## 已知限制

- 只识别以 `/` 分隔的年月日，不识别 `-`、`.`、中文年月日等写法。
- 不做时区、时间部分处理。

## 标准样例

`tests/golden/date_convert/basic/`：`input/input.txt` 每行一个输入（含带首尾空格的 ` 2010/1 ` 和一个空行），`expected/output.txt` 为对应输出。样例文件在 `.gitattributes` 中标记为 `-text`，保证字节不被换行规范化。
