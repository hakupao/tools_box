# 格式转换（format_convert）

四种互相独立的转换模式，一次只能选一种，应用于所选的全部文件。

## 输入

| 模式 | 接受的扩展名 |
| --- | --- |
| CSV → XLSX（`csv_to_xlsx`） | `.csv` |
| XLSX → CSV（`xlsx_to_csv`） | `.xlsx`、`.xlsm` |
| CSV → UTF-8 BOM（`csv_to_bom`） | `.csv` |
| CSV 去引号（`csv_unquote`） | `.csv` |

扩展名与所选模式不符的文件记为错误"文件类型与所选模式不符"，不影响其他文件。选择文件夹时跳过 `~$` 临时文件。

CSV 的编码识别规则见 [README 的"编码规则"](README.md#编码规则)：识别出日文/中文编码时给出提示；歧义时该文件不处理并询问用户；无法识别时报错。页面可手动指定编码（也可按文件指定，优先于统一指定）。

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 输出位置 `output_dir` | 与原文件相同 | 可指定另一个文件夹（不存在则创建） |
| 覆盖原文件 `overwrite_source` | 关 | 仅对 CSV → UTF-8 BOM、CSV 去引号有效；其余两种模式输出扩展名不同，该选项无效 |
| 导出全部工作表 `all_sheets` | 关 | 仅对 XLSX → CSV 有效 |
| 编码 `encoding` / `encodings` | 自动识别 | 手动指定后跳过自动识别 |

## 各模式规则

### CSV → XLSX

- 用标准 CSV 规则（分隔符 `,`）逐行解析，引号内的换行保留。
- 原样写入新工作簿的唯一工作表 `Sheet1`；所有单元格强制为字符串类型，`=SUM(A1)`、`+1` 这类内容不会被当作公式或数字；所有写入的单元格格式为文本（`@`），所以 `007` 不会变成 `7`，长数字不会变成科学计数法。
- 各行长度不一时按原样写入，缺的单元格留空。
- 含 Excel 不支持的控制字符时，该文件报错"第 N 行含 Excel 不支持的控制字符"，不输出。
- 输出名 `<stem>.xlsx`；空 CSV 生成空的 `Sheet1`。每处理 5000 行检查一次取消。

### XLSX → CSV

- 复用[工作表拆分](sheet_split.md)的导出规则（单元格转字符串、日期渲染、去掉末尾空行空列、UTF-8 BOM）。
- 默认只导出第一个工作表，输出名 `<stem>.csv`；开启"导出全部工作表"时每个工作表一个文件，输出名 `<stem>_<安全工作表名>.csv`。
- 无法读取（常见于文件已在 Excel 中打开）记为错误"无法读取文件（可能已在 Excel 中打开）"。

### CSV → UTF-8 BOM

- 按识别出的编码解码，文本原样（包括换行符）以 UTF-8 BOM 写出，不做其他修改。
- 输出名 `<stem>_bom.csv`；开启"覆盖原文件"时写回原文件。
- 是否"已是 UTF-8 BOM"按文件开头的实际字节判断（与所选编码无关）。文件已带 BOM 时不输出，提示"已是 UTF-8 BOM，未生成文件"。
- 空文件输出只含 BOM 的文件。

### CSV 去引号

- 分隔符：对前 1024 个字符用 `csv.Sniffer`（候选 `,` Tab `;` `|`）检测，失败时用 `,`。
- 按标准 CSV 规则解析后重新写出，字段内容原样保留（首尾空格、内部引号都不改）。
- 分隔符不是 `,` 时提示"按「制表符/分号/竖线」分隔识别"。
- 只有字段含任一候选分隔符（`,` Tab `;` `|`，不只是识别出的那个）、`\r`、`\n` 或以 `"` 开头时才加引号（内部 `"` 双写）。这类字段共 `n` 个，`n > 0` 时提示"n 个字段含分隔符、换行或以引号开头，已保留引号"。
- 整行只有一个空字段（原文为 `""`）时写出 `""`，以便和空行区分，不计入 `n`；空行仍写成空行。
- 行尾一律 `\r\n`，编码 `utf-8-sig`。
- 输出名 `<stem>_unquoted.csv`；开启"覆盖原文件"时写回原文件。

例：`"a","  b ","c""d"` → `a,  b ,c"d`；`"x,y","1"` → `"x,y",1`。

## 输出规则

- 目标文件已存在时自动加 `_1`、`_2`……，不覆盖已有文件（"覆盖原文件"除外）。
- 所有输出先写同目录临时文件，成功后原子替换；取消时不留半成品，已完成的文件保留。

## 统计与错误

- `files`：成功输出的文件数；`skipped`：既无输出也无错误的文件数（已是 UTF-8 BOM）；等待选择编码的文件不计入；重新处理时未选择编码的文件计入 `skipped`。
- 写出时被其他程序占用：错误"无法写入输出文件（可能已被其他程序打开）"。
- CSV 读取时被其他程序占用：错误"无法读取文件（可能已被其他程序打开）"。
- 其他异常：错误"转换失败：<原因>"。
- XLSX → CSV 的读取失败和单个工作表写出失败沿用[工作表拆分](sheet_split.md)的错误文字（"读取失败：<原因>"、"<工作表名>: <原因>"），不使用上面的"无法写入输出文件"和"转换失败"。
- 未选择文件：报错"请先选择要转换的文件"。

## v3 变更

- CSV → XLSX：各行长度不一时原样保留（v2 用 pandas，会报错）。
- CSV 去引号：无损——不再改动字段内容，只在必要时保留引号并提示。
- CSV → UTF-8 BOM：默认生成新文件 `<stem>_bom.csv`，不覆盖原文件；已是 BOM 时不重复生成。

## 标准样例

`tests/golden/format_convert/`，共 9 个用例：

- `csv_to_xlsx`：长短不一的行、引号内换行、前导零。
- `xlsx_to_csv_first`：默认只导出第一个工作表，输出 `<stem>.csv`。
- `xlsx_to_csv_all`：两个工作表全部导出。
- `csv_to_bom_gbk`：GBK 输入、保留混合换行。
- `csv_to_bom_already`：输入已带 BOM，不生成输出（没有 `expected/`）。
- `csv_to_bom_ambiguous_chosen`：cp932 / GBK 都能解码的文件，用 `encodings` 指定为 cp932。
- `csv_unquote`：保留空格与内部引号、必要时保留引号。
- `csv_unquote_semicolon`：分号分隔，含逗号的字段保留引号。
- `overwrite_source`：CSV → UTF-8 BOM 加"覆盖原文件"，写回原文件名。
