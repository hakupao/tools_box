# 获取字段（field_extract）

读取文件夹中每个 CSV / Excel 文件的列名行，汇总成一份 CSV 清单。

## 输入

- 所选文件夹中的 `.csv`、`.xlsx`、`.xlsm`（可选包含子文件夹）。同一文件夹内按文件名排序，跳过 `~$` 临时文件。
- 文件名匹配 `file_fields_summary.csv`、`file_fields_summary_1.csv`……（不区分大小写）的文件是本工具以前的输出，不作为输入。
- 所选路径不是文件夹：报错"请选择有效的文件夹"；列名行号小于 1：报错"列名行号必须大于等于 1"；没有可处理的文件：报错"该文件夹中没有 CSV 或 Excel 文件"。

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 列名行号 `header_row` | 1 | 从 1 开始，必须大于等于 1 |
| 包含子文件夹 `include_subfolders` | 关 | 开启后递归处理 |
| 输出位置 `output_dir` | 所选文件夹 | 可指定另一个文件夹（不存在则创建） |
| 编码 `encoding` / `encodings` | 自动识别 | 手动指定后跳过自动识别；`encodings` 按文件指定，优先于统一指定 |

## 规则

- CSV：按编码识别规则（见 [README 的"编码规则"](README.md#编码规则)）解码，用标准 CSV 规则（分隔符 `,`）取第 `header_row` 行作为字段名。字段名原样保留：不改名、不去重、空值保留为空字符串。行数不足则没有字段。
- Excel：只读、取单元格的值（公式取缓存结果）。对每个工作表取第 `header_row` 行，空单元格记为空字符串，去掉行尾的空单元格，字段名为 `工作表名: 值`。某个工作表行数不足则该表没有字段。
- 无法读取（常见于文件已在 Excel 中打开）：错误"无法读取文件（可能已在 Excel 中打开）"；其他读取失败：错误"读取失败：<原因>"。

## 输出

- 汇总文件 `file_fields_summary.csv`，UTF-8 BOM、行尾 `\r\n`，表头 `文件名,字段名`。已存在时自动加 `_1`、`_2`……，不覆盖。
- 文件名列是相对所选文件夹的路径，分隔符统一为 `/`。每个字段一行。
- 没有字段、或读取出错的文件写一行 `相对路径,`（字段名为空）。
- 需要询问编码的文件不写入汇总；汇总文件仍会生成，选择编码重跑后会生成新的汇总。
- 汇总在全部文件处理完后一次写出（部分文件出错也会写出）。取消时不输出。

## 统计

- `files`：成功读取字段的文件数（出错、等待选择编码的不计）。
- `fields`：写入的字段总数。

## v3 变更

- CSV 字段名不再经 pandas 处理：重复列名不再变成 `a.1`，空列名不再变成 `Unnamed: 0`。
- 以前的汇总文件不会被当作输入；汇总默认写在所选文件夹，不覆盖已有文件。

## 标准样例

`tests/golden/field_extract/basic/`：含子文件夹的一组文件——重复列名与空列名的 CSV、两个工作表的 xlsx、GBK 编码的 CSV、空 CSV，对照汇总文件。
