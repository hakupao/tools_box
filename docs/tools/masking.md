# 数据模糊化（masking）

SDTM Pattern1：先扫描一组 CSV 域文件，再按配置把受试者 ID、STUDYID、日期和 DM 中的人员信息替换掉，写入一个新的输出文件夹。分两步：扫描 → 执行。执行只使用扫描结果中的文件，输入文件本身不会被改动。

## 输入

- 只接受存在的 `.csv` 文件（扩展名不区分大小写），重复路径去掉，保持选择顺序。
- 必须有且只有一个 `DM.csv`（文件名不区分大小写）。
- 每个文件都必须有 `USUBJID` 列。列名比较不区分大小写，但不去空格（` USUBJID` 不算）。
- CSV 读取：按编码规则解码（见 [README 的"编码规则"](README.md#编码规则)），标准 CSV 规则（分隔符 `,`，`"` 引号，引号内可含逗号和换行）。空行跳过；字段少于表头的行在右侧补空字符串；字段多于表头的行报错。所有值按文本处理，不做类型转换。

## 参数与默认值

参数保存在配置的 `data_masking_pattern1` 节。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `subject_limit` | 100 | 保留的受试者数，必须 ≥ 1 |
| `usubjid_mode` | `sequential` | `sequential`（顺序编号）或 `rule_chain`（规则链）；其他值按 `sequential` |
| `sequential_prefix` / `sequential_width` / `sequential_start` | `TEST` / 4 / 1 | 顺序编号的前缀、补零位数（小于 1 按 1）、起始号 |
| `rule_chain_steps` | 去前缀 4 位、去后缀 0 位、加前缀 `SKLT`、加后缀 `""` | 规则链步骤列表，每步 `{"op", "value"}` |
| `include_subjid` | 开 | 开启时输出的 SUBJID 列全部清空 |
| `studyid_value` | `[UAT]CIRCULATE` | STUDYID 列的新值 |
| `date_shift_years` | -2 | 日期偏移年数 |
| `date_detect_sample_size` / `date_detect_min_non_empty` / `date_detect_success_ratio` | 200 / 20 / 0.8 | 日期列识别参数 |
| `doctor_fields` / `doctor_value` / `doctor_replace_enabled` | `["INVNAM"]` / `テスト医師` / 开 | DM 医生字段替换 |
| `site_field` / `site_value` / `site_replace_enabled` | `SITEID` / `テスト施設` / 开 | DM 站点字段替换 |
| `age_field` / `age_shift_years` | `AGE` / -2 | DM 年龄偏移（没有开关） |
| 日/月 顺序 `date_orders` | 无 | 每个有歧义的日期列（按 文件名 + 列名）选 `dmy` 或 `mdy`，不保存到配置 |
| 输出位置 `output_parent` | DM.csv 所在文件夹 | 在该文件夹下新建输出子文件夹 |

旧配置中的 `subject_sort`、`date_output_format`、`partial_date_policy` 读取时忽略，保存时不写。

## 扫描规则

1. 没有可用的 CSV：错误"未选择任何 CSV 文件"。
2. 文件名（不区分大小写）重复：错误"文件名重复：<文件名>（输出时会互相覆盖）"。文件名（不区分大小写）为 `usubjid_mapping.csv`：错误"<文件名>：文件名与输出文件 usubjid_mapping.csv 冲突"（否则会被映射文件覆盖；扫描报告是 `.json`，不会与 CSV 输入同名）。
3. 逐个文件读取。编码有歧义：询问编码，并记错误"未确定编码：<文件名>"；编码或 CSV 格式错误："<文件名>：<原因>"；无法打开（常见于已在 Excel 中打开）："<文件名>：无法读取文件（可能已在 Excel 中打开）"；其他读取失败："<文件名>：读取失败（<原因>）"。出错后继续扫描下一个文件。自动识别出 cp932/GBK 时的提示记为警告。
4. 缺少 USUBJID 列：错误"文件缺少 USUBJID 列：<文件名>"。读取失败或缺少 USUBJID 的文件不出现在报告的 `files` 中。
5. 空白值：去掉首尾空格后为空，或小写后等于 `nan`。
6. 每个文件统计：行数（数据行，不含表头）、USUBJID 去重数（去空格、去空白值后的集合大小）、有值字段（至少有一个非空白值的列，按表头顺序）、空字段（其余的列）。
7. 日期列识别：对每个有值字段，取去空格后非空白值的前 `max(1, sample_size)` 个作为样本；能识别为日期的比例 ≥ 阈值即为日期列。阈值 = `ratio` 限制在 [0, 1]；样本数 < `max(1, min_non_empty)` 时阈值为 1.0。"能识别为日期" = 能按下面的日期规则解析，或者是有歧义的斜杠日期。
8. 有歧义的日期列：对日期列的**全部**非空白值判断斜杠日期类型。有歧义的值数 > 0：记录该列，警告"<列> 列有 <n> 个日期无法判断是 日/月 还是 月/日，请选择顺序"；同时存在只能按 日/月 和只能按 月/日 解读的值：警告"<列> 列同时有只能按 日/月 和只能按 月/日 解读的日期，请检查数据"。
9. DM：文件名大写为 `DM.CSV` 的文件个数 ≠ 1：错误"DM.csv 必须且只能有 1 个"。受试者 = DM 中 USUBJID 去空格、去空白值、去重后按 Unicode 码位排序；为空：错误"DM.csv 中没有有效的 USUBJID"。`dm_first_usubjid` 为 DM 行顺序中第一个有效 USUBJID（去空格后）。
10. 有任何错误或没有受试者时扫描不通过，不能执行。文件列表、编码选择或 3 个识别参数变化时需要重新扫描；文件内容被改动（文件大小或修改时间变化）也需要重新扫描。

## 日期规则

输入值先去掉首尾空格。数字含 Unicode 十进制数字（如全角），输出一律为 ASCII 数字（如 `２０２４-０１-１５` → `2022-01-15`）。依次尝试：

1. 完整日期：开头为 `YYYY-M-D` 或 `YYYY/M/D`（年 4 位，月日 1–2 位；两个分隔符各自可以是 `-` 或 `/`，混用如 `2024-01/15` 也接受）。日期之后的剩余部分必须**完整匹配** `^([T ]\d{1,2}(:\d{1,2}(:\d{1,2}(\.\d+)?)?)?)?(Z|[+-]\d{2}(:?\d{2})?)?$`（可选的时间，可以只有小时，如 SDTM 降低精度的 `T13`；可选的时区，可以只有小时，如 `+09`），否则整个值视为无法解析（保持原样）。日期必须真实存在（如 `2023-02-29` 无法解析）。
2. 年月：`YYYY-M` 或 `YYYY/M` → 补成当月 1 日（"补全"）。
3. 年：恰好 4 位数字 `YYYY` → 补成 1 月 1 日（"补全"）。因此任何 4 位纯数字都会被当作年份。
4. 斜杠日期 `a/b/YYYY`（a、b 为 1–2 位）：日/月 和 月/日 两种读法只有一种成立，或两种结果相同时直接采用；两种都成立且结果不同为"有歧义"，按该列选择的顺序解读（`dmy` = 日/月/年，`mdy` = 月/日/年）。斜杠日期后面不能带时间。

偏移：年份加 `date_shift_years`；原日期为 2 月 29 日而目标年不是闰年时取 2 月 28 日；结果年份超出 1–9999 视为无法解析。

输出：`YYYY-MM-DD` 加上原来的时间/时区部分（原样保留），例如 `2024-06-15T13:30:00+09:00` → `2022-06-15T13:30:00+09:00`、`2023-12-31 08:00` → `2021-12-31 08:00`、`2024-06-15T13` → `2022-06-15T13`、`2024-06-15T13+09` → `2022-06-15T13+09`、`2024-07` → `2022-07-01`、`2024` → `2022-01-01`、`03/04/2024`（`dmy`）→ `2022-04-03`。空白值原样保留；无法解析的值原样保留并计数。

## 执行规则

1. 前置检查（按顺序）：扫描未通过 → "扫描未通过，无法执行"；有歧义的日期列中还有没选顺序的 → "请先为 <c> 个日期列选择 日/月 顺序"；`subject_limit < 1` → "输出受试者数必须大于 0"。
2. 受试者 = 扫描得到的受试者列表的前 `subject_limit` 个。
3. 新 ID：
   - 顺序编号：第 i 个受试者（从 0 起）为 `prefix + (start + i)` 补零到 `max(1, width)` 位。
   - 规则链：对原 ID 依次执行每一步。`op` 去空格后不区分大小写；`remove_prefix` 去掉前 n 个字符；`remove_suffix` 去掉后 n 个字符（n ≥ 长度时结果为空）；`prepend` / `append` 在前 / 后加上 `value` 的文本。n 取 `value` 的整数值，负数或无法转换为整数时按 0。未知的 `op` 忽略。
   - 任一新 ID 去空格后为空 → 错误"新 USUBJID 为空（原 ID：<原 ID>）"（先检查）；新 ID 有重复 → 错误"新 USUBJID 重复：<最多前 10 个重复值，用 `, ` 连接>"。
4. 逐个文件处理（顺序同扫描报告中的 `files`）。每个文件按扫描时确定的编码重新读取；读取失败（文件在扫描后被改动、被占用等）→ 错误"<文件名>：读取失败，请重新扫描（<原因>）"，整个执行中止，不留下任何输出。
5. 对每个文件，按以下顺序：
   1. 只保留 USUBJID 去空格后属于所选受试者的行（空白 USUBJID 的行、其他受试者的行全部删除），保持原行顺序。
   2. USUBJID 改为新 ID（USUBJID 列多于一个时报错，见边界情况）。
   3. 开启 `include_subjid`：所有 SUBJID 列全部置为空字符串。
   4. 所有 STUDYID 列：全部置为 `studyid_value`。
   5. 扫描识别出的每个日期列：按日期规则偏移。日期列按列名**完全相同**（区分大小写）匹配。
   6. 仅 DM：开启医生替换时，`doctor_fields` 中扫描时在 DM 有值的列，非空白单元格改为 `doctor_value`；开启站点替换且 `site_field` 扫描时在 DM 有值，非空白单元格改为 `site_value`；`age_field` 扫描时在 DM 有值，每个单元格做年龄偏移。字段名不区分大小写匹配（不去空格），同名的所有列都处理。其他域文件中的同名列不改。USUBJID、SUBJID、STUDYID 列同样按列名不区分大小写匹配。
6. 年龄偏移：空白值原样；去空格后须匹配 `^[+-]?\d+(\.\d+)?$`，否则原样；数字含 Unicode 十进制数字（如全角），输出一律为 ASCII 数字（`４５` → `43`）；按十进制精确相加，结果小于 0 时取 0，保留原值的小数位数（`45` → `43`、`1` → `0`、`30.50` → `28.50`、`+45` → `43`、`1.50` → `0.00`）。
7. 表头原样写出（列名、列顺序不变），文件名与输入相同。
8. 每个日期列中无法解析的值（只统计保留下来的行）个数 > 0：警告"<列> 列有 <n> 个值无法识别为日期，已保持原样"（路径为文件名）。

## 输出

- 输出父目录 = 指定的输出位置，或 DM.csv 所在文件夹（不存在则创建）。在其中新建文件夹 `masked_output_YYYYmmdd_HHMMSS`（本地时间）；已存在时依次尝试 `_1`、`_2`……。
- 先写入同一父目录下的临时文件夹（名称以 `.masked_output_…` 开头、以 `.tmp` 结尾），全部文件写完后整体改名为最终名称。出错或取消时删除临时文件夹，不留下任何输出。无法创建输出父目录或临时文件夹、或最后改名失败：错误"无法创建输出文件夹（<原因>）"（临时文件夹同样删除）。
- 文件夹内容：
  - 各域文件：与输入同名，UTF-8 BOM、行尾 `\r\n`、标准 CSV 引号规则（含逗号、引号、换行的值加引号；引号内的换行原样保留）。
  - `usubjid_mapping.csv`：UTF-8 BOM、行尾 `\r\n`，表头 `OLD_USUBJID,NEW_USUBJID`，按受试者顺序每人一行。
  - `pattern1_scan_report.json`：扫描报告（见下），其中有歧义日期列的 `order` 为执行时选择的顺序。
- **注意**：`usubjid_mapping.csv` 和 `pattern1_scan_report.json` 含有原始 USUBJID，可以据此还原受试者身份，不得与模糊化后的域文件一起分发。

## 扫描报告格式

JSON，格式固定如下：

- 编码 UTF-8，无 BOM；换行 `\n`（LF），文件末尾有一个换行。
- 2 空格缩进；对象的键与值之间为 `": "`，同一层的项之间为 `,` 加换行；空列表写作 `[]`。
- 非 ASCII 字符原样写出，不转义为 `\uXXXX`。
- 键的顺序与下面列出的顺序相同。
- 小数（`ratio`）总是带小数点，如 `0.8`、`1.0`（不会写成 `1`）；整数不带小数点。

键依次为：

- `dm_file`：DM 文件名或 `null`；`dm_first_usubjid`：DM 中第一个有效 USUBJID 或 `null`；`subject_count`；`subjects`。
- `date_detect`：`sample_size`、`min_non_empty`、`ratio`。
- `files`：每项 `file_name`、`encoding`（`utf-8-sig` / `utf-8` / `cp932` / `gbk`）、`row_count`、`unique_usubjid_count`、`non_empty_fields`、`empty_fields`、`date_fields`（均为扫描时、过滤受试者之前的统计）。
- `ambiguous_date_columns`：每项 `file_name`、`column`、`ambiguous`、`day_first_only`、`month_first_only`、`order`（`"dmy"` / `"mdy"` / `null`）。
- `errors`、`warnings`：扫描的错误与警告文字。

只存文件名，不存绝对路径和时间。扫描页面"导出报告"选 `.csv` 时导出列 `file_name,row_count,unique_usubjid_count,non_empty_fields,empty_fields,date_fields`（列表用 `|` 连接），其他扩展名导出上述 JSON。

## 统计

- `files`：写出的域文件数；`subjects`：保留的受试者数；`rows`：保留的数据行总数。
- `dates_shifted`：偏移成功的日期值数（含补全的）；`dates_filled`：其中由 `YYYY` / `YYYY-MM` 补全的个数；`dates_unparsed`：无法解析而保持原样的个数。

## 编码

读取规则见 README；执行时使用扫描时确定的编码（手动选择的编码同样沿用）。所有 CSV 写出为 UTF-8 BOM，报告 JSON 为 UTF-8 无 BOM。

## 边界情况

- USUBJID 两侧有空格（如 ` S1 `）：按去空格后的值匹配，保留并替换为新 ID。
- `nan`（任意大小写）按空白处理：既不是受试者，也不会被医生/站点替换。
- DM 中整列为空的医生/站点/年龄列：不替换，执行前的摘要中也不出现。
- 开启医生替换但没有指定任何医生字段：不替换，摘要显示"DM：未指定医生字段，不替换"；开启站点替换但站点字段为空：不替换，摘要显示"DM：未指定施设字段，不替换"。
- 日期列中的空白值原样保留，不计数。
- 多个列同名时：
  - 关键列（USUBJID、SUBJID、STUDYID 以及 DM 的医生/站点/年龄字段）按列名不区分大小写判断同名。USUBJID 列多于一个 → 错误"<文件名>：USUBJID 列重复"，执行中止，不留下任何输出；SUBJID 清空、STUDYID 设置以及 DM 的医生/站点/年龄处理对**所有**同名列生效（只要其中任一列扫描时在 DM 有值）。
  - 日期列按列名完全相同（区分大小写）判断：日期偏移处理所有与日期列名完全相同的列；仅大小写不同的列（如 `aestdtc` 与 `AESTDTC`）分别识别。
- 取消：在每个文件开始前检查；取消后不留下任何输出。

## v3 变更

- 勾选"处理 SUBJID"时 SUBJID 列直接清空（v2 用 USUBJID 映射替换）。
- 日期偏移后保留时间和时区部分（v2 只输出日期）；日期后带有不符合时间格式的其他内容时视为无法解析，保持原样。
- 有歧义的斜杠日期需要为该列选择 日/月 或 月/日 顺序，未选择不能执行。
- 年龄按十进制相加并保留原小数位数。
- 新增文件名重复检查、与输出文件 `usubjid_mapping.csv` 同名的检查；新 ID 为空时报错。
- 输出先写临时文件夹再整体改名；执行时文件读取失败会中止并要求重新扫描。

## 已知限制

- RELREC、SUPP 域的 IDVARVAL 等其他列中出现的 USUBJID 不会重新映射。
- 没有 USUBJID 列的试验设计域（如 TS、TA）不支持，扫描会报错。
- 斜杠日期后带时间（如 `25/03/2024 10:30`）无法解析，保持原样。
- 缺少中间部分的 SDTM 日期（如缺月份的 `2003---15`）无法解析，保持原样。
- 同一个文件里有两个完全同名、日期顺序都有歧义的列时，它们共用一个 日/月 顺序选择。

## 标准样例

- `tests/golden/masking/sequential_basic/`：顺序编号，保留 2 个受试者；DM 行不按排序、含整列为空的 `ICINVNAM`；AE 含要删除的行（第 3 个受试者、空 USUBJID）、` S1 ` 行、带时间和时区的日期、只有小时的时间（`T13`、`T08+09`）、`YYYY` 与 `YYYY-MM`、`2024-02-29`、含逗号和换行的引号字段、SUBJID 列、一个无法解析的日期。
- `tests/golden/masking/rule_chain_ambiguous/`：规则链（去前 4 位、加前缀 `SKLT`），不清空 SUBJID，不替换医生；AE 为 cp932（只含半角片假名，自动识别）且 `AESTDTC` 含有歧义的斜杠日期，选择 `dmy`。

样例的运行方式：把 `input/` 复制到临时目录，用 `params.json` 的 `profile` 覆盖默认配置并扫描（文件按文件名排序），再以固定时间 `2026-01-02 03:04:05` 执行，输出父目录为一个空的临时目录；生成的文件夹必须是 `masked_output_20260102_030405`，其中所有文件与 `expected/` 对照（`.json` 也逐字节比较）。
