# 全角转半角（width_convert）

## 输入

- `.xlsx`、`.xlsm`（可多个文件，或选择文件夹；跳过 `~$` 开头的临时锁文件）。
- 用 openpyxl 按单元格读取，不依赖 pandas。

## 参数与默认值

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 输出位置 `output_dir` | 与原文件相同 | 可指定另一个文件夹（不存在则创建） |
| 覆盖原文件 `overwrite_source` | 否 | 勾选后运行前二次确认 |

## 处理步骤

1. 逐个文件加载工作簿（`.xlsm` 保留 VBA）。
2. 遍历所有 sheet 的所有单元格，只处理字符串单元格（类型为文本）：
   - U+FF01–U+FF5E 的全角字符减去 0xFEE0，变为 U+0021–U+007E；
   - U+3000（全角空格）变为 U+0020。
3. 其他字符一律不变：日文假名、汉字、半角片假名等。不使用 NFKC。
4. 不处理：公式单元格、数字、日期、空单元格、合并区域中除左上角以外的单元格、sheet 名称。
5. 表头与普通单元格同样处理。
6. 格式、number_format、合并区域保持不变。

## 输出位置与命名

- 输出名：`<stem>_halfwidth<suffix>`，例如 `sample.xlsx` → `sample_halfwidth.xlsx`。
- 默认输出到原文件所在目录；指定了输出文件夹则输出到该文件夹。
- 目标已存在时自动加 `_1`、`_2`……，例如 `sample_halfwidth_1.xlsx`。
- 勾选"覆盖原文件"时，写回原文件本身；否则原文件从不被修改。
- 文件中没有任何需要转换的字符时，不保存任何文件（也不覆盖原文件），记一条警告"未发现需要转换的全角字符，未生成文件"，且不计入 `files`。
- 输出先写入同目录的临时文件，成功后再替换到目标位置；失败时清理临时文件，原文件不受影响。

## 统计与结果

- `files`：成功输出的文件数。
- `cells_changed`：实际发生变化的单元格数。

## 边界情况

- 未选择文件：报错"请先选择要转换的 Excel 文件"。
- 单个文件失败不影响其他文件：
  - 无法写入（常见于文件已在 Excel 中打开）：记为该文件的错误"无法写入输出文件（可能已在 Excel 中打开）"；
  - 其他异常（如文件损坏）：记为"转换失败：<原因>"。
- 失败的文件不产生输出，原文件不受影响。
- 每个文件开始前检查取消；取消后不再处理后续文件，已完成的输出保留。

## 已知限制

- openpyxl 不保留图表、图片、数据透视表等特性，转换后的输出文件可能丢失它们，这也是默认输出新文件的原因；需要这些特性的文件请核对输出后再使用。
- 公式内的字符串字面量不转换。
- 富文本单元格按片段转换文字，各片段的字体保持不变；只要有一个片段变化，该单元格计 1 次 `cells_changed`。

## 标准样例

`tests/golden/width_convert/basic/`：覆盖表头、普通文本、全角空格、数字字符串（文本格式）、日文假名与半角片假名、公式、合并单元格、两个 sheet。
