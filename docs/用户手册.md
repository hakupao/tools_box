# DataForge Studio 用户手册

适用版本：3.0.0。

DataForge Studio 把 CSV / Excel 格式转换、SDTM 数据模糊化、EDC 站点批量添加等日常重复操作放在一个窗口里。本手册说明怎么用；每个工具的详细规则（输出文件怎么命名、特殊情况怎么处理）见各节末尾的"规则说明"链接。

## 1. 安装与升级

**安装**

1. 从 <https://github.com/hakupao/tools_box/releases/latest> 下载安装包 `DataForgeStudio-Setup-3.0.0.exe` 并运行。
2. 默认安装到 `%LOCALAPPDATA%\Programs\DataForgeStudio`，不需要管理员权限。
3. 安装完成后从开始菜单打开"DataForge Studio"。

**从 v2 或更早的 3.x 升级**

- 直接运行新的安装包覆盖安装，不用先卸载。
- 原来的设置会自动带过来：统一配置文件启动时直接读取；程序目录旁边单独保存的数据模糊化配置、EDC 点击位置，第一次打开对应工具时读入。数据模糊化的配置和 EDC 的点击位置都会保留。
- EDC 的旧配置里没有"目标窗口"，第一次使用前需要录制一次，或者手动选择目标窗口（见第 10 节）。
- v2 中的仕様書工作流、死链检测和数据模糊化 Pattern2 已经移除。

**配置和日志在哪里**

在"设置"页点"打开配置文件夹"或"打开日志文件夹"即可。一般位置是 `%LOCALAPPDATA%\dataforge_studio\`。

## 2. 主页

打开程序后先看到主页，分两部分：

- **最近使用**：最近 10 次成功运行的记录，每条显示工具名、输入文件和时间。点一下就跳到对应工具，并把当时的输入文件和参数填好。
  - 如果原来的文件已经被移走或删除，只恢复参数，并在右上角提示哪些文件不存在。
  - 这个工具正在运行时点它，不会改动正在使用的输入。
- **全部工具**：所有工具的卡片，点整张卡片即可进入。

左侧的侧边栏随时可以切换到其他工具或回到主页，底部是"设置"。

## 3. 窗口宽度与布局

工具页会随窗口宽度自动调整排法：

| 窗口宽度 | 排法 |
| --- | --- |
| 宽（全屏或接近全屏） | 左边填输入和参数，右边看结果 |
| 中 | 侧边栏只显示图标；输入、参数、结果从上到下排列 |
| 窄（窗口拉到最小附近） | 单列；参数的名称显示在输入框上方；结果区收成一行摘要，点它展开 |

不管哪种排法，窗口底部都有一条操作栏：进度条、处理到第几个、"取消"按钮和主按钮（例如"开始转换"）。

结果区有三个标签页：

- **结果**：生成的文件路径和统计数字；
- **警告**：有问题的文件，以及原因；
- **日志**：运行过程中的详细记录，出问题时可以把这里的内容发给维护人员。

## 4. 通用规则

所有文件类工具都遵守下面几条：

- **不覆盖原文件**。默认在原文件所在文件夹生成新文件；同名文件已存在时自动在文件名后加 `_1`、`_2`……
- **输出位置**可以改为"指定文件夹…"，所有输出放到你选的文件夹里。
- 只有勾选了"**覆盖原文件**"、并在弹出的确认框中点"确定"后，才会直接改写原文件。改写无法撤销，请先备份。
- 输出的 CSV 一律是 UTF-8 BOM 编码，用 Excel 直接打开不会乱码。
- 一个文件出错不影响其他文件，出错的文件和原因列在"警告"标签页。
- 运行期间输入和参数不能修改；可以切换到其他页面，任务在后台继续。同一时间只能运行一个任务，其他工具的主按钮不可用，旁边显示"××× 正在运行"。
- 运行完成、部分失败、失败、取消，都会在窗口右上角弹出提示条，随后自动消失；详细内容留在结果区。
- 添加文件可以点"选择文件" / "选择文件夹"，也可以直接把文件拖进输入框。选择文件夹时，Excel 的临时文件（`~$` 开头）会被自动跳过。

## 5. 编码选择对话框

读取 CSV 时程序会自动判断编码。大多数文件可以直接识别；只有一种情况需要你来选：文件既能按**日文（cp932）**、又能按**中文（GBK）**读通。这时程序不会猜，而是：

1. 先处理其他文件；
2. 处理完后为每个这样的文件弹出"选择编码"对话框，上下分别显示两种编码读出的前几行；
3. 你选看起来正确（没有乱码）的那一种，点"确定"，程序只对这些文件再处理一次。

对话框里可以勾选"本批其余文件也用此编码"，后面同类文件就不再逐个询问。点"取消"则跳过剩下的文件，它们会在"警告"中标为"未选择编码，已跳过"。

如果你事先知道编码，也可以在参数的"编码"中直接选"日文 (cp932)"或"中文 (GBK)"，就不会再询问。

编码识别的完整规则见 [规则说明：编码规则](tools/README.md#编码规则)。

## 6. 格式转换

**用途**：CSV 和 Excel 互相转换、把 CSV 转成 UTF-8 BOM、去掉 CSV 字段外面的引号。

**操作步骤**

1. 在"转换方式"中选一种：
   - **CSV → XLSX**：每个 CSV 转为一个 Excel 文件，所有单元格按文本保存（不会把 `001` 变成 `1`）；
   - **XLSX → CSV**：Excel 导出为 CSV，默认只导出第一个工作表，勾选"导出全部工作表"则每个工作表一个 CSV；
   - **转 UTF-8 BOM**：自动识别编码后另存为 UTF-8 BOM，已经是 UTF-8 BOM 的文件不再生成；
   - **去除引号**：去掉字段外层的引号，内容保持不变。
2. 添加文件。与所选方式不符的文件会被自动移除并提示。
3. 按需要设置编码、输出位置、是否覆盖原文件。
4. 点"开始转换"。

**输出位置**：默认在原文件旁边，文件名规则见规则说明。

规则说明：[format_convert.md](tools/format_convert.md)

## 7. 工作表拆分

**用途**：把一个 Excel 文件的每个工作表分别导出为 CSV。

**操作步骤**

1. 添加一个或多个 Excel 文件（`.xlsx`、`.xlsm`）。
2. 选择输出位置。
3. 点"开始拆分"。

**输出位置**：默认在原文件旁边，每个工作表一个文件，文件名为"原文件名_工作表名.csv"，例如 `book.xlsx` 的"数据"工作表 → `book_数据.csv`。

规则说明：[sheet_split.md](tools/sheet_split.md)

## 8. 获取字段

**用途**：批量读取一个文件夹中所有 CSV / Excel 的表头，汇总成一份字段清单。

**操作步骤**

1. 选择文件夹；需要连子文件夹一起读时勾选"包含子文件夹"。
2. 设置"列名行号"（表头在第几行，默认第 1 行）。
3. 按需要设置编码（只对 CSV 有效）和汇总输出位置。
4. 点"开始获取"。

**输出位置**：默认在所选文件夹中生成 `file_fields_summary.csv`，每个字段一行，第一列是文件名，第二列是字段名。

规则说明：[field_extract.md](tools/field_extract.md)

## 9. 数据模糊化

**用途**：把 SDTM 数据（Pattern1）处理成可用于测试的模糊化数据：保留部分受试者、替换 USUBJID、日期整体偏移、替换医生和施设等字段。

分三步：**扫描 → 配置 → 执行**。

**操作步骤**

1. **添加文件**：添加同一试验的全部 SDTM CSV 文件，其中必须有且只有一个 `DM.csv`，每个文件都要有 `USUBJID` 列。
2. **扫描**：点"开始扫描"。程序检查文件、统计受试者、找出日期列。结果显示在"扫描结果"卡片中。
   - 扫描未通过时，原因列在"扫描结果"和"警告"中，改好文件后点"重新扫描"。
   - 某些日期列写成 `01/02/2023` 这种形式、分不清是"日/月/年"还是"月/日/年"时，会列在扫描结果中，请逐列选择顺序。
   - 可以点"导出扫描报告…"保存一份扫描结果。
3. **配置**：在"受试者与 ID"和"日期与 DM"卡片中检查参数：输出受试者数、USUBJID 编号方式（顺序编号或规则链）、日期偏移年数、年龄偏移、医生和施设的替换值等。卡片下方会显示示例。"恢复默认值"可以撤销修改。
4. **执行**：检查"执行摘要"，确认无误后点"开始处理"。参数会自动保存，下次打开时沿用。

扫描后如果又改了文件或扫描设置，程序会提示"需要重新扫描"。

**输出位置**：默认在 `DM.csv` 所在文件夹中新建一个 `masked_output_<日期>_<时间>` 文件夹，里面是处理后的各个 CSV、新旧 USUBJID 对照表 `usubjid_mapping.csv` 和扫描报告 `pattern1_scan_report.json`。

> **注意**：`usubjid_mapping.csv` 和 `pattern1_scan_report.json` 里有原始的 USUBJID，可以据此还原受试者身份。这两个文件**不要**和模糊化后的数据一起发给别人。

规则说明：[masking.md](tools/masking.md)

## 10. EDC 站点添加

**用途**：从 Excel 中逐行读取站点编号，在浏览器的 EDC 页面上按录制好的位置自动点击，批量添加站点。

**准备**

- Excel 已打开，并选中第一个站点编号所在的单元格；
- 浏览器已打开 EDC 的站点添加页面。

**第一次使用：录制点击位置**

1. 点"一键录制"。屏幕顶部出现一条深色提示栏。
2. 切换到浏览器的 EDC 页面，点提示栏上的"开始"。
3. 按提示依次点击 7 个位置：新建 → 查找 → 搜索框 → 搜索 → 选择 → ok → 确认。点屏幕最上方提示栏区域不会被记录。
4. 录制完成后自动保存。程序会记住你点击的那个浏览器窗口，作为"目标窗口"。
5. 某一步位置不对时，可以在"点击位置"卡片中单独"重录"那一步。录制中按 ESC 可以取消。

也可以点"选择窗口…"从列表中手动指定目标窗口。

**检查录制结果**：点"回放测试"，屏幕上会依次闪出 7 个标记，看看位置是否对准，这一步不会真的点击。

**运行**

1. 在"运行参数"中确认"最多处理行数"（默认 100，遇到空单元格会提前结束）和"每步间隔（秒）"（默认 0.3，网页反应慢时调大）。
2. 点"开始处理"。**运行期间不要动鼠标和键盘。**
3. 想停下时按 **ESC**，当前这一步做完后停止。
4. 全部结束后，"结果"中显示成功、跳过、出错的行数，"警告"中列出跳过和出错的行及原因，"日志"中列出每个成功的行。

这个工具不会出现在"最近使用"中；点击位置、目标窗口和运行参数会自动保存，下次打开时沿用。

**某一行停下时**：程序出错或你按了 ESC，会弹出对话框，说明是 Excel 哪个单元格、第几步、什么原因，让你选择下一步（见第 14 节的"EDC 停止后怎么选"）。程序不会自动重试，以免重复添加同一个站点。

**限制**：程序只是按记录的位置点击，无法判断每次点击是否真的生效（例如网页还没加载完）。运行结束后请到 EDC 中抽查结果。

规则说明：[edc_site_adder.md](tools/edc_site_adder.md)

## 11. 日期转换

**用途**：把文本中 `2021/2/3` 这种写法的日期转成 ISO 8601（`2021-02-03`）。

**操作步骤**

1. 在左边的"输入"框中粘贴日期，每行一个。
2. 点"转换"，右边显示结果。
3. 点"复制结果"复制到剪贴板。

无法识别的内容原样保留；日期不完整或不存在时只保留有效的部分，例如 `2021/02/31` → `2021-02`。

这个工具不生成文件，也不会出现在"最近使用"中。

规则说明：[date_convert.md](tools/date_convert.md)

## 12. 全角转半角

**用途**：把 Excel 中的全角英文字母、数字、符号和全角空格转成半角，保留原来的格式和公式。

**操作步骤**

1. 添加一个或多个 Excel 文件（`.xlsx`、`.xlsm`）。
2. 选择输出位置；需要直接改原文件时勾选"覆盖原文件"。
3. 点"开始转换"。

**输出位置**：默认在原文件旁边生成"原文件名_halfwidth"加原扩展名的文件，例如 `book.xlsx` 生成 `book_halfwidth.xlsx`，`.xlsm` 文件仍是 `.xlsm`。文件中没有需要转换的字符时不生成文件，并在"警告"中说明。

> 覆盖原文件时，原文件中的图表、图片、数据透视表等可能丢失，确认框里也会提醒。

规则说明：[width_convert.md](tools/width_convert.md)

## 13. 设置

- **主题**：跟随系统 / 浅色 / 深色，选择后立即生效并保存。
- **打开日志文件夹**、**打开配置文件夹**：出问题时可以把日志文件 `dataforge.log` 发给维护人员。
- **清空最近使用**：清除主页上的"最近使用"记录。
- **版本**：显示当前版本号。

## 14. 常见问题

### 提示"无法写入输出文件（可能已被其他程序打开）"或"无法读取文件（可能已在 Excel 中打开）"

文件正在被 Excel 或其他程序使用。关闭 Excel 中的这个文件，再运行一次。其他文件不受影响，已经生成的文件会保留。

获取字段重新处理时，如果原来的汇总文件正在被打开，新汇总会另存为 `file_fields_summary_1.csv` 之类的新文件名，并在"警告"中说明。

### 提示"无法确定编码（日文 cp932 / 中文 GBK 均可解码）"

这是正常情况，说明这个文件两种编码都能读通，程序需要你来选，见第 5 节。看预览中哪一边没有乱码就选哪一边。如果一批文件都是同一种编码，可以直接在参数"编码"中指定，就不会逐个询问。

### EDC 停止后怎么选

对话框提供三个选择：

- **重做本行**：从这一行的第 1 步重新开始。**重做前请先到 EDC 中确认这个站点是否已经添加过**，已经加上的话应选"跳到下一行"，否则会重复添加。
- **跳到下一行**：这一行记为"已跳过"，从下一行继续。
- **结束**：停止整个运行。这一行记为"出错"；如果是在这一行还没开始时按了 ESC，则不算出错。

结束后，"警告"中会列出跳过和出错的行及原因，便于事后补录。

### ESC 怎么停止

- **EDC 站点添加**：运行中按 ESC，当前这一步做完后停下，并弹出上面的三选一对话框。ESC 不会打断正在进行的点击。录制时按 ESC 则取消录制。
- **其他工具**：点操作栏上的"取消"按钮。已经完成的文件保留，正在写的文件不会留下半成品。
- 任务运行中关闭窗口，程序会先询问；确认后取消任务再退出。

### 输出文件在哪里

默认在原文件所在的文件夹（数据模糊化是 `DM.csv` 所在文件夹下的新文件夹）。运行结束后，"结果"标签页列出了每个输出文件的完整路径。

### 遇到其他错误

打开"日志"标签页查看详细信息；或者在设置页点"打开日志文件夹"，把 `dataforge.log` 发给维护人员。
